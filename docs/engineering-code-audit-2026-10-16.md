# Structural check logic audit — ASCE 7-16 / ACI 318-19

Reviewed 16 October 2026. Scope: every C# source file in Inspector.Checks and Inspector.Engine, with supporting inspection of Core contracts, ETABS extraction and regression tests. This is a software engineering/code-method audit, not certification of the attached building model. No live analysis, design or model changes were performed.

**Conclusion.** The application is useful for model screening, but its PASS outcomes must be read against each rule's limited scope. It does not implement complete ASCE/ACI compliance. The most consequential defects were unsupported P–delta inclusion claims, suppressed design failures, misuse of required reinforcement as provided reinforcement, and heuristic comparisons presented as code failures. Corrections are applied to the workspace. Remaining limitations below require additional engineering inputs or extraction work.

**Drift and stability basis.** SEIS-006 already correctly uses design drift ratio = elastic ratio × Cd/Ie. ANA-007 is a generic raw-output comparison and now explicitly directs seismic users to SEIS-006. It must not be interpreted as an amplified seismic drift check.

The formula in the request reverses the amplification factors. ASCE 7-16 Eq. 12.8-16 uses:

`theta = Px * Delta * Ie / (Vx * hsx * Cd)`

Since `Delta/hsx = elasticDriftRatio * Cd/Ie`, the equivalent expression is `theta = Px * elasticDriftRatio / Vx`. The cancellation is valid; force/force and displacement/height are dimensionless. The implemented limit `min(0.5/(beta*Cd), 0.25)` is retained for ASCE 7-16. The permitted adjustment when drift already includes P–delta is not automatically applied because result lineage is unproven. The [ASCE publisher's equation/version history](https://amplify.asce.org/popup-data?apath=%2Fasceworks%2Fstandard%2F9780784415788%2Fpart%2Fprovisions%2Fstandard-chapter%2Fs12%2Fstandard-sec-ver%2Fs12.8.7.ver.atom) shows the earlier equation; newer-edition limit changes were not imported.

**Reinforcement and stiffness interpretation.** ACI Table 6.6.3.1.1(a) nominal inertias are 0.35Ig beams, 0.70Ig columns, 0.35Ig cracked walls, 0.70Ig uncracked walls and 0.25Ig flat plates/flat slabs. These are not universal requirements for every analysis load level or modeling method; permitted alternatives and sustained-load effects require review. Shell shear/axial properties are not automatically identical to flexural inertia. [CSI explains the local-axis mapping and modifier components](https://web.wiki.csiamerica.com/wiki/spaces/etabs/pages/1474670).

For ordinary nonprestressed beams, the SI minimum expression is `As,min = max(0.25*sqrt(fc')/fy, 1.4/fy)*bw*d`, with strengths in MPa, subject to applicability and permitted exceptions. A fixed 0.0033 cannot cover all strengths. Required demand does not establish provided bars. General column reinforcement limits are 1–8% Ag; special moment-frame columns require the separate 1–6% limit. The 4% congestion threshold is a practical screen. Wall 0.0025 is not a universal minimum for every wall class/loading condition. [CSI's API explicitly limits PMMArea to Design mode and PMMRatio to Check mode](https://docs.csiamerica.com/help-files/etabs-api-2016/html/d85059d5-a38c-d7d7-69dc-4bdc7fe21b56.htm).

**Remaining review items, by rule family**

| Rules reviewed | Remaining limitations / necessary follow-up |
|---|---|
| GEO-001/002/006/007/009/010 | Object-node connectivity is not solver-mesh connectivity. Auto-meshing, constraints, rigid zones, springs, offsets and intentional interfaces need separate evidence. Joint whitelisting should identify pairs, not merely a set of names. Boundary checks do not establish polygon planarity or mesh quality. |
| GEO-003/004/011/012/015 | Short-member limits are project criteria. Multi-tower/base-level semantics, auto-select/general sections and diaphragm flexibility still need explicit applicability. Positive dimensions/valid references are definition checks only. |
| CFG-001, MAT-001, LOAD-001/002/006/007/008/009/010/013 | Pattern names and combination existence do not prove ASCE load coverage, coefficients, orthogonal/vertical seismic effects, redundancy or overstrength. Source flags cannot prove effective seismic weight, live-load inclusion or case-specific mass selection. Negative combination factors are legitimate; recursive references are not. |
| ANA-001/002/003/004/008/012/014/015 | Availability, finished status and an extracted inventory do not prove freshness, convergence or stability. Modal/nonlinear indicators and design-code name comparisons need the actual current analysis/design provenance. |
| ANA-007/013, SEIS-006/017 | Confirm raw elastic basis, load scale, Cd/Ie, risk category, structural system, diaphragm-edge/COM drift location, and appropriate Table 12.12-1 limit. Current mapped drift verification covers finished linear-static cases, not complete response-spectrum drift design. |
| SEIS-001/002/003/004/005/013/014/015 | Full hazard/site classification, adopted supplements, site-specific exceptions, SFRS R/Cd/Ω0 applicability, direction-specific periods and case-specific masses remain unverified. Mode 1 may be torsional. Configurable modal participation is a project comparison, not proof of the ASCE modal-completeness requirement/exception. A matching computed base shear does not validate all assumptions. |
| SEIS-007/008/010/011/016/019, AUD-003 | Soft-story thresholds 0.70/0.80 and extreme 0.60/0.70 are correctly represented as triggers. Torsional thresholds 1.2/1.4 need diaphragm/SDC applicability. Ax needs level displacements and accidental torsion initially evaluated without amplification. Bounding floor dimensions are not SFRS dimensions. Overlapping slabs/openings and multiple diaphragms can invalidate area ratios. |
| SEIS-012, SAN-008 | Subtraction of independently enveloped story shears can fabricate floor increments. Use signed, simultaneous subcase/step results before enveloping. Even matching “Max” labels need not represent the same physical state. Direction-specific period/mass and complete floor-force coverage are needed. This remains unresolved. |
| COL-004/007/008, BEAM-004/005/006, WALL-008/009, DETAIL-008 | Most checks examine demand availability or screening ratios, not provided steel, strain limits, shear reinforcement, confinement, splice/development, joint shear, strong-column/weak-beam, wall boundaries or complete seismic detailing. Implement member-level seismic classification before enforcing 6% column limits. DETAIL-008 compares external total area only and still assumes display-area units when no unit is supplied; require explicit schedule units. |
| OPT-001/002; RebarEstimator | Low utilization is only a candidate for review. Check all design stations/combinations, drift, shear, stability and constructability before resizing. Required-steel percentages cannot prove reserve capacity. Volume × kg/m³ is an estimate, not a rebar takeoff or code requirement. |
| SAN-001–008 | 12 kN/m² floor allowance, 1.25 kPa wind pressure, 8–18 kN/m² gravity density, period rules and axial stress bands are heuristics. SAN-001/005 currently envelope individual gravity cases rather than constructing D+L and use absolute axial forces; confirm compression sign and common loading basis. SAN-006 lacks genuine pier assignments, directional amplified design shear and applicable strength-reduction factor. SAN-007 lacks actual foundation geometry, resisting load combinations and hold-down capacity. |
| Catalog/engine | Reserved checks are not implemented, and several formerly numbered checks are absent from the catalog. Force-jump/outlier settings exist without active registered checks. Coverage must not be marketed as complete code compliance. Rule versions remain generic and should be revised under a formal release policy. |

**Recommended threshold policy.** Keep code limits distinct from engineering review bands. Use numerical tolerance only to accommodate computation/display precision, never to relax physical code limits. For rounded ETABS tables, derive tolerance from field precision; the existing 1e-5 base-shear and 1e-6 hazard equality comparisons can be too tight. A disclosed 0.5–1% preliminary consistency band is reasonable pending precision-aware comparison, but is not a code relaxation. The 2% concrete self-weight comparison needs a complete like-for-like load inventory before any equilibrium FAIL. Retain 0.95 PMM as an optional near-capacity warning, >1.0 as failure, and 0.35 utilization/1.2% required steel as optimization candidates only. Keep 40% tributary deviation and 0.40 axial stress warnings provisional until matching service combinations and tributary loads are supplied. Do not invent a universal force-jump tolerance: distinguish real point-load/support jumps from unexplained discontinuities, using simultaneous stations, local axes and a denominator floor.

**ETABS extraction gaps.** Prioritize: (1) lateral-case initial/stiffness source, gravity preload and convergence; (2) source timestamps/model revision and design-section versus analysis-section consistency; (3) explicit pier/spandrel assignments and shell local axes; (4) true provided bars, effective depth, reinforcement fy, wall type and lightweight-concrete factors; (5) amplified wall shear Ve, governing design combination, in-plane force direction, individual/aggregate wall geometry and applicable phi; (6) case-specific mass source and directional modal/period mapping; (7) signed subcase/step identities, source precision and table units; (8) partial-row recovery when one API value is invalid. Column/beam extraction should normalize “No Message” before nulling required-area outputs, as pier extraction already does. Repeated geometry/definition reads are useful but do not establish analysis/design freshness. API error arrays should be retained even when another numerical field is invalid.
